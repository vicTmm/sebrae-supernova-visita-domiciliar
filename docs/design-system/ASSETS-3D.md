# Visitário — assets 3D, estudo 01

Demo: `http://localhost:5173/demo-visitario.html`, com Vite em execução. Os renders individuais estão em `frontend/public/brand/visitario/`.

O painel `direcao-visual.png` guarda a primeira versão do estudo, que ainda traz o nome Vitalink. Os prompts abaixo registram como os renders foram gerados.

Produção: imagegen integrado. Renders raster, não modelos 3D editáveis. O painel ilustrado é conceitual; seus campos e afirmações não especificam funcionalidades entregues. A demo HTML utiliza as fontes reais e dados fictícios, sem persistência.

O app usa `visita-app.webp`, uma versão de 360 × 240 px de `visita.png`, no cartão do caso fictício. Essa versão entra no cache offline da PWA.

Create a polished 1600x1100 art direction presentation board for Vitalink, a Brazilian professional home visit clinical documentation app for public health. Huge elegant Bricolage Grotesque-style heading 'Vitalink' and subtitle 'O cuidado continua. O registro acompanha.' Left editorial brand introduction, right extremely refined realistic desktop app screen with sidebar 'Nova visita', 'Histórico', heading 'Registro da visita', white clinical form sections 'Identificação', 'Sinais vitais', primary button 'Revisar evolução'. Inter style UI typography with comfortable spacing. Bottom strip shows palette #145B49 #F5F7F8 #172B35 and typography examples Inter and Bricolage Grotesque. Integrate gorgeous restrained premium 3D sculptural linked rounded glass and dark teal forms, a small satin ivory house and teal medical clipboard. Off white background, sophisticated public sector healthcare SaaS, excellent hierarchy, no gradients in UI, no purple, no cartoon humans. This is a visual concept with fictional data only. Portuguese text. Design like a premium crafted brand studio presentation, no excessive tiny labels.
